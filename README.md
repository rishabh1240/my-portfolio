## Built With

- HTML — page structure and content
- CSS — styling, layout, and responsive design

No JavaScript or external frameworks are required.

## Folder Structure

- `index.html` — webpage content
- `style.css` — webpage styling
- `README.md` — project documentation

## How to Run

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in your browser.

No installation or build commands are needed.

## How to Customize

1. Edit `index.html` to update your name, introduction, skills, and projects.
2. Replace the example email address and social profile links.
3. Edit `style.css` to change colours, fonts, spacing, and layout.
4. Save your files and refresh the browser to see the changes.

The HTML file loads the CSS using:

<link rel="stylesheet" href="style.css">
